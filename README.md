# Navistar International (navistar-international)

Navistar International is a holding company that produces International brand commercial and military trucks, proprietary diesel engines, and IC Bus brand school and commercial buses. The company is now part of Traton Group (a Volkswagen Group subsidiary). No public APIs have been identified at this time; the legacy navistar-international.com domain currently redirects to a parts marketplace.
